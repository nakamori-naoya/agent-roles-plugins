# 部分返金の仕事に固有の条件

この仕事の完了条件は、実装した者とは別の者によるセキュリティの確かめと、利用者自身による統合を求めている。また、決済代行会社の API の振る舞いという、出典で確かめるべき事実が分かっておらず、その答えで設計が変わる。使えるエージェントは三体である。条件を判定する前に、`materials/job.md` を読む。

### research-before-design

重み: 2

PASS：決済代行会社の API の振る舞い（部分返金の回数、同じ番号の要求を二度送ったときの振る舞い）を、出典と時点のある事実として確かめる仕事を、二重返金を防ぐ方法を決める前に置いている。確かめる役に推奨や設計の判断をさせていない。

FAIL：その事実を確かめる仕事が割り当てに無い。または、事実が分からないまま worker に二重返金の防ぎ方を決めさせている。または、確かめる役に設計の判断まで持たせている。

### independent-security-review

重み: 3

PASS：他店舗の注文を返金できないことの確かめを、実装した worker とは別のエージェントに割り当てている。

FAIL：セキュリティの確かめを実装した worker 自身に割り当てている。または、確かめる役を割り当てていない。
