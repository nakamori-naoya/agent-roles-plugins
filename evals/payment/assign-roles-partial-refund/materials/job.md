# 部分返金を足す仕事

## 目的

決済の API に、支払済みの注文の一部だけを返金する操作を足す。今は全額の返金しかできず、店舗の担当者は、一部の商品だけ返品されたときに、全額を返してから差額を請求し直している。

## 完了条件

部分返金の API が、返金の合計が支払額を超えないことを守る。同じ返金の要求が二度届いても二重に返金しない。決済代行会社の部分返金の API を呼ぶ。既存の全額返金の test と、新しく足す test がすべて通る。セキュリティの観点（他店舗の注文を返金できないこと）で、実装した者とは別の者が確かめる。main への統合は、利用者が自分で行う。

## 分かっていないこと

決済代行会社の部分返金の API が、一つの支払に何回まで部分返金を受け付けるか、返金の要求を同じ番号で二度送ったときにどう振る舞うかは、まだ誰も確かめていない。公開の開発者向けの資料と、代行会社への問い合わせで確かめられる。この答えによって、二重返金を防ぐ仕組みをこちらで持つか、代行会社に任せるかが変わる。

## 使えるエージェント

同時に動かせるエージェントは三体である（Claude Code が二体、Codex が一体）。どのエージェントも repository を読み書きでき、公開の web の資料を読める。
